# 内部结构
## 通用寄存器
- 数据寄存器（AX、BX、CX、DX）
- 指针寄存器（SP、BP）
- 变址寄存器（SI、DI）
### 数据寄存器
4 个 16 位数据寄存器，分为 8 个 8 位（高低位）寄存器
AX->AH, AL（Accumulator）
累加器，传输所有 I/O 指令，存放中间运算结果
BX->BH, BL（Base）
基址寄存器：在 **间接寻址**中用于存放基地址
CX->CH, CL（Count）
计数寄存器：在循环或串操作指令中存放计数值
DX->DH, DL（Data）
数据寄存器：在 I/O 指令中存放端口地址，在乘除法中存放高 16 位
### 指针寄存器
SP（Stack Pointer）：堆栈指针，指向栈顶的偏移地址
BP（Base Pointer）：基址指针，在访问内存时存放内存单元的偏移地址
### 变址寄存器
SI（Source Index）：源变址寄存器
DI（Destination Index）：目标变址寄存器
## 段寄存器
作用：存放相应逻辑段的段基地址
8086/8088 有 20 条地址总线，最大可寻址内存空间为 $2^{20}$ =1 MB
物理地址范围：00000H~FFFFFH
8086/8088 是 16 位体系结构微处理器，最大可寻址内存空间为 $2^{16}$ =64 kB
直接管理 64k个内存单元
代码段 CS（Code）：存放当前使用的**程序代码段**的端地址
数据段 DS（Data）：存放当前使用的**数据段**的端地址
附加段 ES（Extra）：存放操作的数据
堆栈段 SS（Stack）：通常存放断点的地址信息
指令指针寄存器 IP：存放 EU 要执行的下一条要取的指令的**偏移地址**
FLAGS:
标志寄存器：存放运算结果的特征
一、状态标志

| 标志位    | 名称                            | 功能说明                                                 |
| :----- | :---------------------------- | :--------------------------------------------------- |
| **CF** | 进位标志 (Carry Flag)             | 无符号数运算时，若最高位产生进位（加法）或借位（减法），CF = 1；否则为 0。也用于移位/循环指令。 |
| **PF** | 奇偶标志 (Parity Flag)            | 运算结果低 8 位中 1 的个数为偶数时，PF = 1；为奇数时，PF = 0。用于校验。        |
| **AF** | 辅助进位标志 (Auxiliary Carry Flag) | 运算时低 4 位向高 4 位产生进位或借位，AF = 1；否则为 0。用于 BCD 码运算的十进制调整。 |
| **ZF** | 零标志 (Zero Flag)               | 运算结果为 0 时，ZF = 1；否则为 0。常用于条件跳转判断。                    |
| **SF** | 符号标志 (Sign Flag)              | 运算结果最高位为 1（负数）时，SF = 1；为正数时，SF = 0。用于有符号数运算。         |
| **OF** | 溢出标志 (Overflow Flag)          | 有符号数运算结果超出表示范围时，OF = 1；否则为 0。用于检测有符号数溢出。             |

二、控制标志

| 标志位    | 名称                             | 功能说明                                                        |
| :----- | :----------------------------- | :---------------------------------------------------------- |
| **TF** | 陷阱标志 / 单步标志 (Trap Flag)        | TF = 1 时，CPU 进入单步执行模式，每执行一条指令后自动产生一次内部中断（中断 1），便于程序调试。      |
| **IF** | 中断允许标志 (Interrupt Enable Flag) | IF = 1 时，CPU 允许响应可屏蔽中断请求（INTR）；IF = 0 时，禁止响应。对非屏蔽中断（NMI）无效。 |
| **DF** | 方向标志 (Direction Flag)          | 控制串操作指令的地址变化方向。DF = 0 时，地址自动递增（SI/DI 自增）；DF = 1 时，地址自动递减。   |

|  段寄存器  | 偏移地址（有效地址） | 用途说明                                 |
| :----: | :--------- | :----------------------------------- |
| **CS** | **IP**     | 取指令（代码执行）                            |
| **SS** | **SP**     | 堆栈操作（PUSH/POP/CALL/RET/INT/IRET）     |
| **SS** | **BP**     | 访问堆栈中的数据（以 BP 为基址寻址）                 |
| **DS** | **SI**     | 字符串/数据传送的**源**地址                     |
| **DS** | **DI**     | 一般数据访问（以 DI 为偏移寻址）                   |
| **DS** | **BX**     | 一般数据访问（以 BX 为基址寻址）                   |
| **ES** | **DI**     | 字符串操作的**目的**地址（如 `STOS`、`MOVS` 的目的端） |
