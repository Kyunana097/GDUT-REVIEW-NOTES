# 3.1 8088/8086 指令格式
机器指令：二进制数组成的代码

## 指令格式
操作助记符【目标操作数】【，源操作数】【；注释】
e.g. MOV AX, BX; 把 BX 的值赋给 AX
操作助记符：指令助记符，以符号形式给出指令的操作
操作数：指令要处理的**数据**或数据所存放的**地址**
寻址方式：指令中关于如何获得**操作数有效地址**的方法
# 3.2 8088/8086 寻址方式
## 1. 立即寻址
MOV AL, 12 H; AL<-12 H
MOV AX, 1234 H; AX<-1234 H
操作数直接在指令里
## 2. 寄存器寻址
操作数在寄存器中
段寄存器限制使用，同为寄存器时需长度相同
## 3. 内存寻址
操作数放在**存储器**中
表现形式：\[**操作数在内存中的偏移地址**]
### 直接寻址
指令中直接给出操作数的**偏移地址**
MOV AL, [1200 H]
MOV AH,[1200 H]
直接寻址下，操作数默认在数据段 DS
数据允许存在其他段，但需要段说明
### 间接寻址
数据在内存中的偏移地址放在寄存器中
只能放间址寄存器 BX, BP, SI, DI
段地址取决于选择哪一个间址寄存器 (BX, SI, DI 为数据段，BP 为堆栈段)
### 相对寻址
操作数的偏移地址为寄存器的内容**加上一个偏移量**
### 基址变址寻址
MOV AX,[SI+BX]
相当于[SI]+[BX]
只能是基址+b
例：MOV AX，BX    寄存器寻找
MOV
# 3.3 8088/8086 指令系统
## 数据传送指令
把**数据或地址**传动到**寄存器或存储单元**中
1. 通用数据传送指令
	1. 数据传送指令：MOV
		1. 格式：MOV dest, src
		2. 操作：src->dest
	2. 堆栈操作指令：PUSH、POP
		1. 入栈格式：PUSH src
		2. 出栈格式：POP dest 
	3. 数据交换指令：XCHG
	4. 换码（查表转换）指令：XLAT
2. 算数运算指令
	1. 拓展指令：CBD
	2. 加减指令：ADD、
		1. 加法指令：ADD
			1. 格式：ADD DST, SRC
			2. 操作：DST<-DST+SRC
		2. 带进位加法指令：ADC
			1. 格式：ADC DST, SRC
			2. 操作：DST<-DST+SRC+CF
			3. 注意：使用前需使用 CLC 清零 CF
		3. 加一指令：INC
		4. 减法指令：SUB
			1. 格式：SUB DST, SRC
			2. 操作：DST<-DST-SRC
		5. 带借位减法指令：SBB
			1. 格式：SBB DST, SRC
			2. 操作：DST<-DST-SRC-CF
		6. 减一指令：DEC
3. 逻辑运算类
	1. 逻辑“与”指令 AND
		1. 格式：AND DST, SRC
		2. 操作：DST<-DST $\wedge$ SRC
	2. 逻辑“或”指令 OR
		1. 格式：OR DST, SRC
		2. 操作：DST<-DST $\lor$ SRC
	3. 逻辑“非”指令 NOT
		1. 格式：NOT DST
		2. 操作：按位取反
	4. 逻辑“异或”指令 XOR
		1. 格式：XOR DST, SRC
		2. 操作：DST<-DST $\oplus$ SRC
	5. 测试指令 TEST
		1. 格式：TEST DST, SRC
		2. 操作：按位进行逻辑与运算，结合 ZF 对特定位进行判断
4. 移位指令
	1. 算数左移指令 SAL
		1. 格式：SAL DST, CNT
		2. 操作：对 DST 中的有符号数进行左移 CNT 位，右侧补零
		3. 注意：可按标志位来判断是否溢出
	2. 逻辑左移指令 SHL
		1. 格式：SHL DST, CNT
		2. 操作：对 DST 中的无符号数进行左移 CNT 位，右侧补零
		3. 注意：可等同于乘 2 操作
