# 3.1 8088/8086 指令格式
机器指令：二进制数组成的代码

## 指令格式
操作助记符【目标操作数】【，源操作数】【；注释】
e.g. MOV AX, BX; 把 BX 的值赋给 AX
操作助记符：指令助记符，以符号形式给出指令的操作
操作数：指令要处理的**数据**或数据所存放的**地址**
寻址方式：指令中关于如何获得**操作数有效地址**的方法
# 3.2 8088/8086 寻址方式
## 1. 立即寻址
MOV AL, 12 H; AL<-12 H
MOV AX, 1234 H; AX<-1234 H
操作数直接在指令里
## 2. 寄存器寻址
操作数在寄存器中
段寄存器限制使用，同为寄存器时需长度相同
## 3. 内存寻址
操作数放在**存储器**中
表现形式：\[**操作数在内存中的偏移地址**]
### 直接寻址
指令中直接给出操作数的**偏移地址**
MOV AL, [1200 H]
MOV AH,[1200 H]
直接寻址下，操作数默认在数据段 DS
数据允许存在其他段，但需要段说明
### 间接寻址
数据在内存中的偏移地址放在寄存器中
只能放间址寄存器 BX, BP, SI, DI
段地址取决于选择哪一个间址寄存器 (BX, SI, DI 为数据段，BP 为堆栈段)
### 相对寻址
操作数的偏移地址为寄存器的内容**加上一个偏移量**
### 基址变址寻址
MOV AX,[SI+BX]
例：MOV AX，BX    寄存器寻找
MOV
# 3.3 8088/8086 指令系统
## 数据传送指令
把**数据或地址**传动到**寄存器或存储单元**中
1. 通用数据传送指令
	1. 数据传送指令：MOV
		1. 格式：MOV dest, src
		2. 操作：src->dest
	2. 堆栈操作指令：PUSH、POP
		1. 入栈格式：PUSH src
		2. 出栈格式：POP dest 
	3. 数据交换指令：XCHG
	4. 换码（查表转换）指令：XLAT
