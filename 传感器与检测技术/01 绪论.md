# 1.1 自动检测技术概述
## 1.1.1 自动检测技术的重要性
本课程主要用电测的方式来测量非电量
## 1.1.2 自动检测系统的组成
传感器：非电量转换为有对应关系且便于应用 （通常是电量）的测量装置
测量电路：把传感器信号转化为电压或电流信号
输出单元：指示器、记录仪、累加器等
## 1.1.3 自动检测系统的发展趋势
性能增强、仿生、更高精度
# 1.2 传感器概述
## 1.2.1 传感器的定义
国标 GB 7665-87
概念：
1. 是测量装置，能完成检测任务
2. 输出量是某一被测量
3. 输出是某种物理量
4. 输入输出有对应关系
## 1.2.2 传感器的组成
敏感元件：直接感受被测量，并输出与被测量成确定关系的物理量
转换元件：将敏感元件的输出作为输入，把输入转换成电路参数
转换电路：将上述电路参数转换为电量输出
## 1.2.3 传感器分类
工作机理：物理型、化学型、生物型
物理型：
- 构成原理：
	- 结构型：物理学场定律
	- 物性型：物质定律
- 能量转换：能量控制型、能量转换型
- 物理原理
- 用途：位移、压力、振动、温度
# 1.3 测量误差与数据处理
## 1.3.1 测量误差的概念和分类
有关测量技术中的部分名词
- 等精度测量：测量条件相同
- 非等精度测量：测量条件不同
- 真值：理想条件的真正值一般情况下未知
- 实际值：测量得到的逼近真值的结果
- 标称值：测量器具的标示值
- 示值
- 测量误差

误差的分类
1. 系统误差
2. 随机误差
3. 粗大误差
## 1.3.2 精度
准确度：反映系统误差的影响程度
精密度：反映随机误差的影响程度
精确度：反映系统误差和随机误差综合的影响程
